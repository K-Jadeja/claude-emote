# Overlay Package Resource Collision

Date: 2026-07-27

## Impact

`npm run overlay:package` built the web UI but failed to produce application
packages. Neutralino reported that the configured icon did not exist.

## Root cause

The initial scaffold used `desktop/dist` for two incompatible purposes:

- input web resources generated by esbuild;
- output packages generated by `neu build`.

The window icon also used a document-root URL rather than the project-relative
resource path Neutralino's packager resolves.

## Fix

- `desktop/resources` is now the generated web-resource input.
- `desktop/dist` is reserved for Neutralino package output.
- the icon path is `/resources/assets/default/idle/idle.png`.

This follows Neutralino's input/output layout and removes the ambiguous path.

## Regression coverage

`tests/integration/desktop-overlay-build.test.ts` runs the real resource build.
The build fails unless the configured resource root matches
`desktop/resources`, differs from package output, and contains the configured
icon. `tests/unit/desktop-shell-source.test.ts` also locks the config contract.
